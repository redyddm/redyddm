### 👋 Hi there!

I am a **Master 2 Student in AI Engineering** at **University Paris 8**. My focus is on building robust data pipelines and applying mathematical models to solve problems in **Earth Observation** and **Recommendation Systems**.

---

### 📡 Geospatial Intelligence & Remote Sensing

I specialize in building end-to-end pipelines for satellite imagery, from automated acquisition to feature detection.

* **Automated Data Acquisition:** Expertise in querying satellite APIs (**OpenEO**, **EarthAccess**) to retrieve multi-source data (Sentinel-1, Sentinel-2, ECOSTRESS).
* **Image Processing:** Handling CRS, image stacking, and calculating spectral indices (NDVI) for biodiversity monitoring.
* **Feature Extraction:** Detecting vegetation patterns and linear features (hedges) using distinct spectral signatures.

### 🧠 Machine Learning & NLP

I work on the algorithmic side of data science, focusing on recommendation engines and text vectorization.

* **Recommender Systems:** Implementation of **Collaborative Filtering** (Matrix Factorization: SVD, NMF, KNN) and Content-Based approaches.
* **NLP & Vectorization:** Using **S-BERT** and **Word2Vec** to transform textual data (titles, descriptions) into dense vector representations.
* **Metric Evaluation:** Rigorous model assessment using RMSE and precision analysis.

### 🛠️ Engineering & Visualization

I believe that good models need good interfaces to be useful.

* **Dashboarding:** Building interactive web apps with **Streamlit** for data exploration and model demonstration.
* **Desktop GUIs:** Developing custom tools with **Tkinter** for real-time data labeling and visualization.
* **Data Stack:** Python, Pandas, NumPy, Scikit-Learn.
